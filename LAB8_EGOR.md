# Егор — лабораторная №8: растеризация и Z-буфер

В панели «Егор — лабораторная №8: Z-буфер» выберите «Закраска с Z-буфером».
Переключатель «Показать 3 перекрывающихся объекта» добавляет куб и октаэдр к
текущей модели. Основную модель можно загружать из OBJ и преобразовывать
существующими средствами. Каркасный режим оставлен для сравнения.

Реализация находится в `zbuffer_renderer.h/.cpp`. Для каждого кадра создаются
белый буфер цвета и буфер глубины с бесконечными значениями. Грани после
видового преобразования и отсечения у перспективной камеры разбиваются на
треугольники. Растеризация использует координаты центров пикселей и
барицентрические веса. Глубина вычисляется отдельно в каждом пикселе; при
перспективной проекции она корректируется через `1/w`. Пиксель записывается,
только если новая глубина меньше сохранённой. Все объекты сцены используют
один буфер глубины, поэтому порядок их обхода не определяет видимость.

В модуле не выполняются отсечение нелицевых граней, управление камерой,
освещение и текстурирование — это отдельные задачи команды. Публичный метод
`WireframeCanvas::setAdditionalModels` позволяет передать другие модели для
совместной отрисовки без изменения растеризатора. Цвет каждого объекта пока
фиксированный и служит для проверки перекрытия.

Алгоритм соответствует формальному описанию Z-буфера в лекции №10, слайд 32.
Преобразование в пространство камеры и перспективное деление основаны на
лекции №9. Проверки выполняются командой
`ctest --test-dir cmake-build-debug --output-on-failure`.
